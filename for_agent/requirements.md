## 1. システム概要
* **システム名称（仮）**: 中学受験 心情語マスター（Kokugo Emotion Words App）
* **目的**: 中学受験国語（特に物語文読解）で合否を分ける重要心情語（全272語）を、スマートフォン上で反復学習し、苦手な語句を定着させる。
* **主要プラットフォーム**: スマートフォンブラウザ（PC・タブレット表示にもレスポンシブ対応）
* **想定利用者**: 家族（最大5名、Googleアカウント別個別データ管理）

---

## 2. システムアーキテクチャ & 技術スタック

| レイヤー | 採用技術 | 選定理由・補足 |
| :--- | :--- | :--- |
| **フロントエンド & アプリ** | **Python (Streamlit)** | 迅速なUI構築、状態管理、Pythonのエコシステム活用 |
| **バックエンド DB** | **Google Cloud Firestore** | サーバーレス、無料枠内運用（1日5万回読取/2万回書込）、ユーザー別学習履歴の永続化 |
| **認証方式** | **Google OAuth 2.0** | 事前登録 Gmail アドレスのみログイン可能なホワイトリスト方式 |
| **インフラ / ホスティング** | **Google Cloud Run** | フルマネージドコンテナ、HTTPS自動化、min-instances=0で低コスト（月額ほぼ0円）運用 |
| **単語マスターデータ** | **CSV（メモリ展開）** | `raw_data/word-list/all_words.csv`（全8分類・272語）を起動時にメモリロード |
| **機密情報管理** | **.env / secrets.yaml (`.gitignore` 済)** | OAuthクライアント情報、ホワイトリストGmailアドレス一覧 |

---

## 3. 認証 & ユーザー管理要件

1. **Google OAuth 2.0 ログイン**:
   * 初回アクセス時、Googleログイン画面へ誘導し認証を実施。
2. **ホワイトリスト認可**:
   * 認証成功後、取得したメールアドレスが `.env` / `yaml` に登録されたホワイトリストに含まれているかを判定。
   * 含まれていない場合は「アクセス権限がありません」と表示し、アプリの利用を遮断。
   * ホワイトリスト設定ファイルはリポジトリの `.gitignore` 対象として安全に管理。
3. **マルチユーザー・データ分離**:
   * 最大5名の家族ユーザーごとに、Googleアカウントの一意な識別子（メールアドレス）で学習履歴を分離保存。

## 4. 機能要件

### 4.1. 画面構成 & ナビゲーション
* **サイドバー（開閉トグル可能）**:
  * モバイルでの画面有効活用のため、表示/非表示を自由に切り替え可能。
  * 画面メニュー：
    1. **クイズ（学習モード）**
    2. **苦手ノート（間違えた問題一覧）**
    3. **心情語辞典（全272語の一覧・検索）**
    4. **ユーザー情報・ログアウト**

---

### 4.2. クイズ機能（学習モード）

#### (1) 基本出題形式
* **モード1（心情語 → 意味）**:
  * 提示された「心情語」の意味として最も適切なものを4つの選択肢から選ぶ。
* **モード2（意味 → 心情語）**:
  * 提示された「意味」に合致する心情語を4つの選択肢から選ぶ。
* **4択生成ロジック**:
  * 正解1つ ＋ ダミー（誤答）3つ。
  * ダミーは、全272語の中から**正解以外の単語を毎回ランダムに3つ自動抽出**して動的生成。
* **セッション単位**:
  * **1セッション = 10問1セット**。

#### (2) サブモード（出題範囲の絞り込み）
1. **全カテゴリからランダム**（全272語から出題）
2. **カテゴリ固定**（全8分類の中から1つを選んで集中特訓）
3. **苦手復習モード（過去に1度でも間違えた問題のみ出題）**
   * 間違えた履歴のある問題の中からランダム出題。
   * **開放条件**: 過去に間違えた問題が **10問以上** 蓄積されている場合のみ選択可能（10問未満は選択不可・進捗メッセージ表示）。
   * **解除ルール**: 管理者がバックエンド（DB）を直接操作しない限り、自動でリストから削除されることはない（間違えた問題として蓄積され続ける）。

#### (3) 回答・判定・解説フロー（1問1答）
1. **問題画面**:
   * モード1なら「心情語」、モード2なら「意味」を表示。
   * **ルビ（読み仮名）確認機能**: 通常はルビなし。ボタンまたはポップオーバーをタップすることで読み仮名を確認可能。
   * 4つの選択肢を表示し、選択した後に「回答する」ボタンを押下して判定に進む。
2. **回答ボタン押下**:
   * 即座に「正解（○）」または「不正解（×）」を表示。
   * 正解の選択肢をハイライト表示。
   * **解説表示**:
     * **「意味・ニュアンス」**: 回答後に常時表示。
     * **「文脈例・つまずきポイント」**: アコーディオンまたはトグルボタンを押すと「入試物語文での代表的な場面・文脈例」および「小学生がつまずきやすい点・類語との識別ポイント」を展開表示。
   * 間違い履歴（不正解回数、総出題回数）をバックエンド（Firestore）へ自動記録。
3. **「次の問題へ」ボタン**:
   * 次の問題へ進行。
4. **10問終了時（結果画面）**:
   * 「10問中 ○問正解！」のスコア表示。
   * 今回間違えた問題のサマリー一覧。
   * 「もう一度解く」「モード選択に戻る」ナビゲーション。

---

### 4.3. 苦手ノート機能（間違えた問題一覧）
* 過去に1回以上間違えた問題の一覧を表示。
* 表示項目：
  * 心情語（タップで読み表示）
  * 分類（カテゴリ）
  * 不正解回数 / 総出題回数 / 不正解率（%）
  * 意味、場面・文脈例、つまずきポイント
* ソート機能（不正解回数が多い順、不正解率が高い順、カテゴリ順など）。

---

### 4.4. 心情語辞典（全272語一覧・検索）
* 全272語をカテゴリ別・50音順・難易度別（並・中・高）で閲覧可能。
* キーワード検索（単語名、読み、意味など）。
* 単語カードをタップ・展開すると、意味・例文・つまずきポイントを詳細表示。

## 5. データモデル設計（Cloud Firestore）

```
users (コレクション)
  └── {user_email} (ドキュメント)
        ├── email: string (メールアドレス)
        ├── last_login_at: timestamp (最終ログイン日時)
        └── stats (サブコレクション)
              └── {word_no} (ドキュメント: 単語No.1〜272)
                    ├── word: string (心情語)
                    ├── category: string (カテゴリ)
                    ├── total_attempts: number (総出題回数)
                    ├── incorrect_count: number (不正解回数)
                    ├── incorrect_rate: number (不正解率: incorrect_count / total_attempts)
                    ├── has_ever_failed: boolean (過去に1度でも間違えたか)
                    ├── last_attempt_at: timestamp (最終出題日時)
                    └── last_result: "correct" | "incorrect" (直近の正誤)
```

## 6. 非機能要件 & 運用方針

1. **スマートフォンUI最適化**:
   * 4択ボタンのタップ領域を指で押しやすい十分な高さ（min-height 48px以上）で確保。
   * 小学生が読みやすい視認性の高いフォントサイズと配色。
2. **セキュリティ & 機密情報保護**:
   * Google OAuth Client ID / Secret、許可Gmailリストは `.env` / `secrets.yaml` で管理し、リポジトリへのコミットを禁止。
3. **インフラ & コスト**:
   * Cloud Run（min-instances=0）と Cloud Firestore の無料枠（1GB、5万読取/日）を活用し、月額コストほぼ0円で運用。
